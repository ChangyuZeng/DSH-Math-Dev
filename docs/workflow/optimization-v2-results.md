# 第二轮工作流实验与审计结论

日期：2026-11-06。实验版本为 `0.12.0`，精确提交 `02077550e8a34a2397616038b34b74a1839b9679`。审计后修复单独作为 `0.12.1` 交付，未在本轮补跑。协议见 [optimization-v2.md](optimization-v2.md)，产品契约见 [workflow-v2.md](../../contracts/workflow-v2.md)。

**本轮不支持推广 verify-revise B。** 开发阶段在 17/36 次运行后因独立审计确认的 B 分支任务要求遗漏而终止；另 19 次开发运行及全部 18 次条件保留运行均未启动。已开始的第 17 次运行正常收尾，原始数学成功、恢复失败、成本和日志全部保留。停止依据是预注册的无差异缺陷前提失效，与成本方向无关。B 默认不选中，工具工作流本身也仍需显式启用。

## 冻结边界与统计范围

- A 为 `model-directed-v1`，B 为 `verify-revise-v1`；只将验证/定向修订策略作为实验因素。传输、工具、检查器和归档为两组共享实现。
- 固定 `gpt-6-astra/max`，串行、干净会话与隔离目录，平衡的预定 A/B 顺序；每次求解最多 120 个物理模型尝试，失败和重试计入，无累计时间或 token 上限。
- 计划开发集 6 题 × 2 配置 × 3 次；保留集仅在正向规则与无差异缺陷等前提全部成立后启动。没有追加配置、重复次数、恢复探针或新一轮求解。
- 两次初始接通检查均成功，合计 89 tokens，单列费用范围。最终求解账本有 360 个物理请求，重试 0，未知实验请求 0。实现及审计代理的账单不可独立取得，因此其用量、所有模型合计用量和货币成本保持未知。
- 正式成功要求原生显式提交和独立新进程检查通过；模型判断不是数学证明。事后检查不改写正式提交记录。

协议规范化 SHA-256 为 `a779d414083a4c87b5edf45440e20eb3e9217b4acfae9ffd477c10ae945814db`；协议文件精确字节 SHA-256 为 `2623c6c4352896b6dde725298d98075cf4fd8931441ac8a6b130ac90aab2cc42`。两种哈希口径不同。实验源码清单 SHA-256 为 `6edd71908f95db86be27064e29049975a901c5c3b80a33a51ed9c1eacec38c33`。

## 独立审计及限制

D5-r3-B 的 11 个 worker 请求均携带完整阶段目标；切换到修订后，21 个 reviser 请求的首条消息均遗漏该目标。首个 reviser 请求整体不含恢复清单要求。初始 A/B 阶段目标相同，这表明缺陷发生在触发后的输入构造，而非冻结配置文本。机器检查仅核对源码、隔离及检查器身份；采集器固定写入的 `differential_defect=false` 不能证明没有差异缺陷。最终解释明确记录独立审计发现并禁止晋级。

第 5 个 reviser 请求后来通过工作区脚本读回了部分恢复信息，所以不能声称修订器从未看到恢复要求。D5-r3 的 B/A token 比为 3.9745331401、耗时比为 2.4216601936；这些比值不能因果归于输入遗漏。没有把低成本、时间改善或模型自评当成推广依据。

另有共同的辅助恢复格式问题：原公开说明要求保存 JSON 文件，但未明确检查器接受裸数组。六个 D5 的原始恢复结果均为失败；其中三次保存了匹配哈希的 45 个文件，也不能据此证明其自定义编码可恢复。唯一运行的 D6-A 则在新进程中从第 20 个检查点恢复，40 个中间文件的恢复通过；该题没有配对的 B 结果。

第一轮曾出现的 23 次 `TRANSPORT_SEND` 缺乏足够分阶段证据，实际根因仍未知。本轮实现可区分连接、发送、响应头、流、解码与终止等阶段，且保留保守重试和未知用量边界；这是可审计性及离线回归方面的进展，不是对旧故障根因的追溯证明。

## 审计后的交付修复

`0.12.1` 在独立交付 worktree 完成，冻结实验源码和原始结果未改变：

1. 程序失败及建议性验证失败触发的两条新修订路径均复制当前动作的阶段目标、输出契约，保持新上下文隔离；缺失目标时拒绝派发修订请求。
2. 公共 D5/D6 恢复说明明确裸数组、元素范围和精确文件字节 SHA-256，不改变数学证书检查器。
3. 修复离线边界回归发现的阶段末尾状态覆盖问题：正在执行的最后一个槽位结束后仍保留审计暂停，不能自动打开晋级。实际实验在第 17 个槽位停止，未触及该边界。

修复前的回归分别暴露 3 个 Node 和 2 个 Python 失败；修复后定向测试全部通过。最终完整构建及测试通过：Python 514 项中 482 通过、32 项可选外部适配测试跳过；Node 424 项全部通过。实际操作系统隔离测试包含在默认测试中。界面、安装文件哈希及原位/搬移导出验收证据随本地交付包保存；本轮不更新 Desktop。

本次发布仅公开源码、测试、协议及此汇总。原始运行数据、模型上下文、审核包、配置和凭据保持本地，不进入 Git。修复后的 B 仍为实验开关；本轮没有证明其效果，不续跑到获得有利结果。
